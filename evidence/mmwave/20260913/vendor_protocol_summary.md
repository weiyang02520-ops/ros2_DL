# 4D 成像毫米波 Demo 协议摘要

来源：`4D成像雷达使用说明（上手必看）.pdf`，表 1 “Demo 输出协议”（资料页 8–11）。

| 层级 | 字段 | 资料给出的值/单位 |
|---|---|---|
| 帧包 | 包头 | `0xFFEEFFDC` |
| 帧包 | 包尾 | `0xFFEEFFD3` |
| 帧包 | 帧周期、点数、帧号、处理时间 | 以 32 bit 打包字段给出 |
| 点云包 | 点云包头 | `0xFFDDFECB` |
| 点云点 | X/Y/Z | `int16`，`0.001 m` |
| 点云点 | SNR | `uint16` 线性相对值 |
| 点云点 | 速度 | `int16`，`0.1 m/s` |
| 串口 | 通信参数 | `3000000, 8N1` |

资料没有在可读文字中明确给出完整字节序、点数到包长的最终拼接规则、不同型号的协议差异和 `track_id/confidence` 的来源。实现实时解析器前，必须用目标实物的原始串口帧逐字段验证。
