## 证据口径

| 标签 | 含义 | 不能据此宣称 |
| --- | --- | --- |
| `LOCAL_ONLY` | 文件、纯函数或本地契约验证 | 已部署、设备正常、路线可跑 |
| `TARGET_WRITTEN` | 目标机已写入并核对内容 | 进程启动、ROS 数据有效 |
| `TARGET_VERIFIED` | 对应目标机运行链有真实观测 | 全场景通过或运动安全 |
| `REMOTE_VERIFIED` | 远端接口与数据往返有真实证据 | 任务物理完成 |
| `NOT_PROVEN` | 证据不足或尚未执行 | 空数据不能当通过 |

各项分别记录对象、日期和限制，标签不自动升级。接口通过不代表整车通过。

## 维护约定

1. 接口变更同步改契约及行为测试，不锁死展示文案。
2. 部署说明写明位置、副作用、备份和回滚。
3. 性能数字附环境、原始数据和计算方式。
4. 文档中的现场步骤不代表本轮已执行。实机启动、导航、遥控和巡逻由现场人员执行。
