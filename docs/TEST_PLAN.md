# 测试计划

核对日期：2026-10-15。本计划保护真实回归，不以数量或覆盖率证明整车可用。遵守 [好测试规范](好测试规范.md) 及仓库三个测试与运动边界技能。

## 一、分层与退出条件

| 层级 | 范围 | 执行者 | 通过含义 |
| --- | --- | --- | --- |
| 静态 | 补丁、Python 语法、文档引用、路径 | Agent | 文件一致，不代表运行正常 |
| 离线单元 | 地图像素、缩图、CSV、统计、证据门槛 | Agent | 确定性行为受保护 |
| 本地接口 | 请求模型、鉴权、路由错误、状态反馈 | 依赖匹配后离线执行 | 软件契约有效，不是 ROS 已执行 |
| 目标机只读 | 已运行节点、话题、TF、日志和状态 | Agent 可只读 | 对应观测有效，不证明实际运动 |
| 现场闭环 | 控制、定位、导航、巡逻、停止 | 现场人员 | 仅对已记录场景成立 |
| 远端闭环 | 身份、资产、事件、弱网恢复 | 授权环境中的执行者 | 远端往返有效，不代表底盘完成 |

不能用 FakeBridge、合成数据、静态字符串断言或空测试骨架证明实机通过。缺依赖导致跳过也不是通过。

## 二、本轮定向回归

从仓库根目录运行；不安装软件、不联网、不连接硬件、不运行全仓库测试。依赖为当前 Python 环境中已有的 pytest、NumPy、Pillow 和 PyYAML。命令使用单行，可在 PowerShell 或 Linux 终端运行。

~~~text
python -m pytest -q -p no:cacheprovider src/ylhb_mobile_bridge/test/test_map_snapshot.py src/ylhb_base/test/test_position_error_evaluator.py src/ylhb_base/test/test_relocalization_evaluator.py src/ylhb_base/test/test_feature_repeatability_evaluator.py src/ylhb_base/test/test_teacher_requirements_evaluator.py
~~~

| 风险 | 测试文件 | 行为断言 |
| --- | --- | --- |
| 未知区域被显示为可通行 | test_map_snapshot.py | 205 灰、25/65 分界及纵向翻转 |
| 缩图改变地图身份 | 同上 | PNG 尺寸变化，原图元数据不变 |
| 缩图边界导致零尺寸或异常 | 同上 | 参数夹紧、长宽比、最小边长 |
| CSV 缺失高程被算成零误差 | test_position_error_evaluator.py | 缺失、空白保留 None，不进入高程统计 |
| 非法数值行污染结果 | 同上 | 非法行跳过，其他有效行保留 |
| 人工介入被算作自主恢复 | test_relocalization_evaluator.py | 三种结果独立计数，人工结果不算成功 |
| 没有成功仍生成恢复耗时 | 同上 | 仅成功且有耗时的记录进入时间统计 |
| 重构偷偷改变统计口径 | 同上 | 保留现有偶数样本的上中位数 |
| 坐标系混用或重复匹配 | test_feature_repeatability_evaluator.py | 拒绝坐标系变化，一对一匹配 |
| 空证据或合成输入通过要求 | test_teacher_requirements_evaluator.py | 证据不足不得给出整体完成 |

重构前先运行新增行为断言，之后再改实现。禁止为了让测试变绿修改预期的统计含义。

本轮另提供 [前后对照脚本](validation/compare_offline_refactor.py)，使用固定种子比较基线 Git 源码和当前文件。基线标识、实际结果及局限见 [本轮验证记录](validation/20261015_OFFLINE_REPORT.md)。它不采集或模拟真实机器人完成状态。

## 三、接口回归骨架

复用桥接包已有 test_schemas.py、test_mobile_bridge_server.py、test_platform_cloud_client.py 等，不为每个路由另建空文件。增加测试前先核对 Python、Pydantic、FastAPI、httpx 及 ROS 导入条件。

优先检查以下行为，每项需真实断言而非占位 pass：

1. 本地鉴权开启时，无令牌和错误令牌拒绝，正确令牌可读状态。
2. 本地与平台鉴权叠加时，两层凭据均满足，缺任何一层均拒绝。
3. 云连接已配置时，入站部署和执行默认拒绝，不发布系统命令。
4. 返回 accepted 仅表示已接收，客户端仍等待关联执行反馈。
5. 无地图返回 no_map，不生成全白假图。
6. 地图变更和上传任务创建失败分开表达，避免客户端误判回滚。

本轮没有修复依赖迁移问题，不把无法导入的接口测试算作已验证。精确结果写入 [变更说明](CHANGELOG_20261015.md)。

## 四、只读现场检查

前提是现场人员已启动并授权观察现有系统。以下仅列允许的只读形式，不由本轮连接执行：

~~~bash
ros2 node list
ros2 topic list -t
ros2 topic info /scan --verbose
ros2 topic info /odom --verbose
ros2 topic info /map --verbose
ros2 lifecycle get /controller_server
~~~

持续监听必须设定观察时长并保存输出。话题类型正确还需检查时间戳、频率、坐标系和失效状态；lifecycle 查询服务不可用则记录失败，不改状态补救。

## 七、本次集成整理的定向测试与可运行骨架

本节对应 CHANGELOG_DRAFT.md 和 ADR-001 至 ADR-003，是对既有计划的增量补充，不覆盖前文历史测试结果。本轮工作是离线数据处理和文档整理，不是一次实机运行故障修复；不会因为新增测试而改变启动门槛。

### 7.1 默认入口

前置条件：Python 3.10 或以上的项目开发环境，当前解释器已安装 pytest。命令在 Windows 或 Linux 上运行，不需要 ROS、GPU、相机、CAN、SSH 或云凭据。

~~~bash
python scripts/run_offline_integration_checks.py
~~~

脚本以自身位置定位仓库，只调用下列白名单测试并传递退出码：

- src/ylhb_base/test/test_feature_repeatability_evaluator.py。
- src/ylhb_base/test/test_teacher_requirements_evaluator.py。

如果解释器缺少 pytest，命令失败，不自动安装或切换环境。成功只表示白名单检查通过；失败需先看具体案例和输入，不把历史已存在的其他问题顺手混入修复。测试只写临时目录和 pytest 缓存，不写真实采集证据。

### 7.2 新增行为保护

| 编号 | 输入与步骤 | 预期行为 | 阻止的真实误判 |
| --- | --- | --- | --- |
| O-01 | 单帧对传入负数、零、NaN、无穷大距离 | 明确 ValueError | 负距离平方后继续匹配，或得到无意义分数 |
| O-02 | 相邻非空帧混用空间点与旧 ID，交换顺序；同时调用单对/汇总入口 | 两个方向和两个入口都拒绝 | 把数据格式错误算成零重复率 |
| O-03 | 合法旧 ID 帧对 | LEGACY_ID 仍有效，单对和汇总结果一致 | 新校验误伤历史兼容路径 |
| O-04 | 空数据配非法距离 | 仍先拒绝参数；合法空数据规则不变 | 因数据量不同而漏过相同非法配置 |
| O-05 | 临时 CSV 写入两帧合法空间点，经 main 输出 JSON；再传非法距离 | 文件读取与输出成功；错误调用返回 1 | 只测纯函数而漏掉命令行接线 |

O-05 的 CSV 是测试数据，不标记为真实采集，不纳入实机证据。原有一对一匹配、坐标系变化、空特征和池化/平均/最小指标检查继续保留。

### 7.3 骨架如何扩展

此处骨架是可执行的有限测试入口，不是只有 pass 的空文件。增加检查前先确认它保护哪一种公开行为，以及是否已有适合扩展的测试文件。不要把全仓库递归发现、ROS 启动、硬件探测或网络请求加入默认入口。

若后续出现真实运行故障，按 ROS 实践规范先收集日志、定位依赖顺序，再做最小修复；不得用本轮骨架替代实际故障证据。需要新依赖时，先在隔离开发环境说明版本和用途，不自动修改全局安装。

### 7.4 目标机与现场交接

以下均为待执行计划，不是本轮结果。涉及启动、改变状态或运动的操作由现场人员执行；Agent 不代发速度、导航目标、巡逻命令、初始位姿或 lifecycle 改变。

| 阶段 | 执行者与前置条件 | 留存证据 | 放行/中止 |
| --- | --- | --- | --- |
| T-01 构建与配置 | 授权维护者，在匹配 ROS/SDK 的目标机，仅构建不启动 | 构建输出、包和依赖版本、最终参数来源 | 缺依赖或配置不一致则停止，不伪装完成 |
| T-02 数据与 TF | 现场人员已安全启动；Agent 仅可有限只读观察 | scan/IMU/odom 的类型、频率、时间、frame_id 和 TF 发布者 | 数据过期、TF 冲突或时钟不一致不进入运动 |
| T-03 地图与路线 | 现场人员确认当前地图和受控场地 | 地图身份、摘要、尺寸、原点和路线绑定 | 错绑定应拒绝，不能绕过校验 |
| T-04 实际任务 | 现场人员确认急停、看护、区域并执行任务 | 请求、接收、执行状态、事件和真实终态 | accepted 不算到达，异常立即按现场安全流程中止 |
| T-05 停止与控制权 | 现场人员制定受控试验 | 输入源、仲裁状态、真实停止效果和时间 | 有抢占、不受控运动或失联不停即停止验收 |
| T-06 远端与弱网 | 授权测试网络和脱敏资产，不影响其他设备 | 本地队列、摘要、远端资产确认和错误恢复 | 入队不算远端收到，鉴权失败不算临时网络波动 |

每条记录使用前文模板，保存时间、环境、执行者、输入、原始输出及结论。未执行保持 NOT_PROVEN；成功也仅对应被验证场景，不宣称所有路线和所有工况通过。
