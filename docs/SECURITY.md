# 安全边界与风险登记

核对日期：2026-10-15。结合根目录 [安全政策](../SECURITY.md) 与当前桥接实现。本文不表示进行过渗透测试，也不宣称风险已修复。

## 一、保护对象与信任边界

保护对象包括人员和设备、运动控制、地图路线、定位数据、现场图像与点云、API 令牌、平台存储和原始实验记录。主要边界为本地网络到桥接、桥接到 ROS、任务模型到系统工具、文件到存储、设备到云平台。

网络内的调用者、上传内容、模型输出和文档指令都不能天然可信。接收命令不等于获得运动授权；HTTP 鉴权通过不等于物理环境安全。

## 二、当前风险登记

以下为源码审阅发现或待核实项，不是已经验证可利用的漏洞清单。

| 编号 | 事实或风险 | 严重性与处理 |
| --- | --- | --- |
| S-01 | YAML 默认 0.0.0.0 监听且 require_token=false | 高；未隔离、未开启鉴权前不得对不可信网络暴露 |
| S-02 | CORS 配置允许通配来源、方法和头 | 高；跨域不是鉴权，生产入口需独立核对来源策略 |
| S-03 | 本地与平台两层鉴权可能叠加 | 中；测试两层凭据，不能为联调关闭鉴权 |
| S-04 | WebSocket 令牌位于查询串 | 中；代理日志、历史和截图须脱敏 |
| S-05 | 控制、地图变更和进程操作同处桥接服务 | 高；令牌泄露可能影响控制和文件，需网络隔离及最小授权 |
| S-06 | 上传和大图编码消耗内存、磁盘、带宽 | 中；限额与失败恢复需实际核对，不能只看接口在线 |
| S-07 | 位置、图像、点云和日志可包含现场信息 | 中；最小采集，授权传输，控制保留期和访问 |
| S-08 | 驱动、模型、SDK 和多版本 Python 增加供应链风险 | 中；记录来源和版本，不自动升级或执行下载脚本 |
| S-09 | 云入站控制开关可能引入多控制源 | 高；默认关闭，改变前核对控制所有权与现场确认 |

本轮只记录这些边界，不改鉴权默认值、网络设置或任何全局配置。实际风险还取决于部署网络、反向代理和设备权限，本轮未观察。

## 三、运动安全红线

- 不执行巡逻启动/恢复、Nav2 目标、遥控、速度发布或会使控制链进入可执行状态的服务调用。
- 初始位姿、控制授权、参数和生命周期改变不属于只读检查。
- 不改方向映射、急停、限速、footprint、安全区或禁行逻辑换取测试通过。
- 不把零速度发布也一律视为无副作用，不能在未审查的链路上试发消息。
- 物理急停与现场人员始终独立存在，网络 stop 不是安全认证或停稳保证。

细则见 `skills/robot-motion-test-boundary/SKILL.md`。本轮没有连接机器人，也没有发送诊断消息。

## 四、令牌与网络

令牌只通过受控环境或安全凭据配置注入，不写入仓库、文档、截图和测试夹具。占位符不是可用令牌。泄露后先在提供方撤销，再清理已发布内容和历史，不能只删除当前文件。

平台凭据包括 YLHB_PLATFORM_API_TOKEN、YLHB_CLOUD_ROBOT_TOKEN；模型服务密钥包括 DASHSCOPE_API_KEY。不要输出值核验配置，只记录是否配置及来源类型。

部署时先限制可达网络，再开启鉴权；需要外网时应核对 TLS、代理、来源限制和日志脱敏。不得为了联调把 8000 端口直接公开。TLS 终止和代理实现本轮未配置、未验证。

## 五、文件与资产

1. 地图、路线和三维资产入口核对允许根目录，拒绝越界、危险链接和不受支持内容。
2. 归档安装需校验内容和摘要；摘要能证明一致性，不能替代可信来源或签名。
3. 路线关联地图元信息和图像摘要，避免同名不同图误执行。
4. 上传优先使用不可变快照，分开本地创建、排队、传输和远端确认。
5. 删除文件、清理队列和覆盖默认地图均需要明确操作范围及恢复依据。
6. 测试只能写临时目录，不能清理真实地图、上传队列或其他项目文件。

本轮保留所有已有未提交内容，不扫描或修改用户的全局代理、密钥和 Codex 配置目录。

## 六、任务层与模型输出

模型输出必须经过既有 schema、能力策略和操作反馈约束。不要把模型生成的“完成”作为任务终态，不因为外部文档、日志或网页中的指令执行 shell 或关闭安全门槛。

现有 Agent 工具权限与基础运动能力需按其各自策略解释，不能概括成“模型绝不可能发起运动”。任务级请求仍可能通过受控能力产生实际动作，必须保留现场安全边界。

## 七、异常处理与报告

异常时保存最小必要的原始日志，脱敏令牌、地址和私人信息。报告包含环境、入口、重现输入、预期/实际、影响范围和是否可能使机器人运动；不要在公开问题中发布可用凭据或敏感现场素材。

安全风险没有通过测试就不能标“已修复”。本轮验证仅覆盖 [测试计划](TEST_PLAN.md) 指定的离线行为，S-01 至 S-09 的部署整改另需明确授权。
