## 3. 失败前后对照

修改实现前，先把行为回归加入已有测试文件，执行：

~~~bash
python -m pytest -q src/ylhb_base/test/test_feature_repeatability_evaluator.py
~~~

当时结果：5 个案例失败、5 个通过。失败为负数、零、NaN、无穷大距离未抛错，以及混用空间点/旧 ID 未抛错。失败指向公开行为，不是对源码字符串或界面文案的检查。

修复方式：抽出已有有限正数规则，供单帧对和汇总入口共用；在帧对匹配入口拒绝不同特征表示。合法匹配算法、统计公式、空帧处理和输出字段保持原样。

随后补合法旧 ID 兼容与空数据非法距离案例，定向测试入口实际通过。教师要求评估器已有捕获 OSError/ValueError 的路径；新增拒绝会进入不可评测理由，不需要降低真实证据要求。

## 5. 有效输入前后兼容性

使用一次性 Python 验证程序读取 Git HEAD 中 feature_repeatability_evaluator.py 为基线，并加载本次实现，对比 dataclass 转换后的全部指标字段。

固定随机种子为 20261015。生成 200 组合法序列，每组 2 至 8 帧、每帧 0 至 6 个特征，匹配距离在 0.01 至 1 之间；每组分别构造空间点和旧 ID 两种合法表示，共比较 400 组聚合结果。空间点统一使用 laser 坐标系，ID 从有限集合无放回抽样。结果全部相同，空指标结果也保持一致。

该比较仅适用于生成器覆盖的合法输入，不构成形式化等价证明，也不证明真实激光特征质量。基线文件在本轮开始时没有未提交修改；这不是对整个工作树与 HEAD 的等价比较。
