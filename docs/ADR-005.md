# ADR-005：五处低风险重构只整理纯数据职责

- 日期：2026-10-15。
- 状态：本轮采用。
- 范围：地图快照和离线评估器，不含地图管理及运动控制。

## 背景

用户要求至少五处安全小步重构。当前工作树已有其他地图管理与视觉改动，且没有本轮实机故障复现。为完成数量而改控制链、算法或配置，会增加不必要风险。

因此优先选择输入输出明确、已有离线验证基础的纯数据路径。测试保护灰度语义、统计口径和缺失值，不假装验证机器人。

## 决策与五处边界

| 编号 | 位置 | 改动 | 必须保持 |
| --- | --- | --- | --- |
| R-01 | map_snapshot.py | 提取占用值转像素函数 | 205 未知、25/65 分界及数据类型 |
| R-02 | 同上 | 提取最大边尺寸处理 | 只缩小、比例、下取整、最小一像素及最近邻 |
| R-03 | 同上 | 提取 PNG 与 Base64 编码 | RGB、PNG 优化及 ASCII 字符串 |
| R-04 | position_error_evaluator.py | 合并可选高程 CSV 数字读取 | 空白为 None，非法行仍跳过 |
| R-05 | relocalization_evaluator.py | 用一次分类计数替代重复遍历 | 三种结果独立，原分母与上中位数不变 |

保持公开函数名、参数默认值、输出键、CLI 格式、异常路径和统计口径。新增内部函数不作为外部稳定 API。

## 实施方式

1. 先运行已有定向测试取得基线。
2. 补充公共行为断言，在旧实现上验证。
3. 分别提取职责，不增通用工具库、依赖或全局配置。
4. 运行相同定向测试，对旧实现和新实现做确定性输入输出比较。
5. 记录结果及环境限制，不宣称性能提升或实机通过。

## 未采用的方案

- 不重写地图管理：已有未提交改动，容易冲突。
- 不整理底盘、导航和三个核心模型：缺少本轮运行证据且风险高。
- 不建立统一评估框架：超过小步重构范围，会影响数据与报告口径。
- 不顺手迁移 Pydantic 或全局依赖：不属于纯数据重构，可能影响所有接口。

## 后果与回滚

职责更清楚，但不会自动改善地图精度、导航表现或真实性能。需要维护少量私有函数及行为测试。

回滚按本轮文件差异逐项恢复，不执行 reset/clean，也不回滚其他已有修改。每个重构点可独立检查，实际交付按定向测试和差异比较一起验收。

若后续改变像素阈值、缩放或统计定义，应视为行为变更，不能继续沿用“保持不变”的结论。
