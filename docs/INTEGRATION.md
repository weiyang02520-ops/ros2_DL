# 系统集成说明

核对日期：2026-10-15。描述源码连接和验收依赖，本轮没有运行 ROS 或机器人。

## 一、运行与修改边界

项目说明的目标环境是 Ubuntu 22.04、ROS 2 Humble 和 Jetson。本轮开发机为 Windows，部分 Python 离线逻辑可以验证，但 Linux 驱动、ROS 消息生成、CUDA 和 TensorRT 均需目标机另验。

本轮不改底盘方向、限速、CAN、串口、导航参数、MODEL-1/2/3、驱动或服务配置。纯数据处理重构不改变规划或控制策略。

## 二、依赖与放行条件

| 层 | 前置条件 | 有效观测 | 不足以放行 |
| --- | --- | --- | --- |
| 构建 | ROS、接口包和依赖可用 | 对应包构建和导入结果 | Windows 测试通过 |
| 硬件数据 | 供电、设备映射、驱动和时钟正确 | 连续、新鲜的 scan、IMU、odom | 设备文件存在 |
| TF | 每条变换来源明确 | 时间连续、无发布冲突的坐标链 | 只收到一次变换 |
| 地图与定位 | 地图语义正确、定位有效 | 地图、实际位姿和 `map → odom → base_link` | 静态伪造定位变换 |
| Nav2 | 所需数据、TF、生命周期正常 | 节点状态、Action 服务和日志 | launch 进程存在 |
| 巡逻 | 当前地图与路线一致、执行器可用 | 命令至终态关联完整 | HTTP accepted |
| 上传 | 快照、令牌、网络和持久化正常 | 远端确认和本地任务一致 | 文件存在或仅入队 |

不要在生产者尚未启动时，用其尚未产生的输出作为永久启动门槛。也不能绕过控制锁或安全条件制造表面成功。

## 三、控制链与进程所有权

桥接默认手动输入为 `/cmd_vel_manual`，手动授权为 `/dg/control/manual_authorized`。名称来自桥接配置，不表示任意发布者有控制权。

巡逻使用 `/patrol/command`、`/patrol/status` 和 `/patrol/event`。系统级命令与状态使用 `/inspection_ai/system_command` 和 `/inspection_ai/system_status`。命令已接收必须继续等待真实执行反馈，不能直接显示完成。

现场核对以下内容，本轮不启动、不发布：

1. 最终底盘速度来源，以及仲裁、锁和限速链是否唯一、有效。
2. bringup、导航和巡逻是否存在重复实例及所有者冲突。
3. 物理急停是否可用，网络停止请求不能替代物理急停。
4. 云端与本地控制是否抢占，参见 [ADR-006](ADR-006.md)。

## 四、地图与路线闭环

地图身份不能只看文件名。路线绑定校验涉及 YAML、图像、分辨率、原点、宽高和图像摘要；以 `patrol_route_store.py` 和 [路线字段参考](路线JSON字段参考.md) 为准。

快照只供显示：未知和中间占用显示为灰度 205；0～25 为白色；65 及以上为黑色。像素纵向翻转并按需缩小。元数据保留原图尺寸和分辨率，不能把缩略图坐标直接当世界坐标。

默认地图确认、改名、删除均有副作用。预览通过不能替代保存、绑定和实地路线验收。地图管理文件已有其他改动，本轮不修改。

## 五、独立视觉与三维资产

- 感知、独立视觉、ZED 和三维建图分别核对依赖，不自动绑定机械臂或底盘。
- 节点存在不代表相机有效，必须记录真实帧、时间戳和设备信息。
- 区分采集输入、重建结果、不可变快照、上传任务和远端资产标识。
- 上传成功不代表识别准确、定位可靠或机器人任务完成。

## 六、联调步骤

1. 本地运行 [测试计划](TEST_PLAN.md) 的定向离线回归。
2. 目标机只构建相关包，不启动 bringup 或导航。
3. 对现场人员已启动的系统做只读观测，核对类型、频率、TF 和新鲜度。
4. 由现场人员执行受控任务，采集命令、执行和终态的完整证据。
5. 单独验证远端往返和断网恢复，再核对报告与原始数据。

各步保存环境、时间、命令、输出、执行者和失败原因；未执行项标记 `NOT_PROVEN`。

## 七、故障排查

| 表现 | 优先检查 | 不应直接做 |
| --- | --- | --- |
| 接口在线但不执行 | 权限、控制来源、执行器和反馈 | 绕锁直接发速度 |
| 路线已接受未开始 | 地图绑定、Nav2 和执行关联 | 把 accepted 改为成功 |
| 预览为空 | map 新鲜度、尺寸、数据长度和缓存 | 生成假地图替代 |
| 定位跳变 | 时钟、TF 来源、传感器质量和日志 | 增加冲突 TF 发布者 |
| 上传长期等待 | 队列、凭据阻塞、磁盘和响应 | 无限重试鉴权失败或输出密钥 |
| 统计为空或不通过 | 采集类别、有效行、真值、清单和协议 | 用合成数据填实机证据 |

安全边界见 [安全说明](SECURITY.md) 和 `skills/robot-motion-test-boundary/SKILL.md`。
